Политика конфиденциальности

Оператор персональных данных — владелец сайта digitalsub.ru. Реквизиты оператора и контакт для обращений: [заполнить].

1. Какие данные мы собираем

Через форму заявки: имя, номер телефона или имя пользователя Telegram, описание задачи и параметры расчёта стоимости. Также технические данные: IP-адрес, сведения о браузере и адрес страницы, с которой отправлена заявка.

2. Зачем

Чтобы связаться с вами по заявке, подготовить предложение и заключить договор. Данные не используются для рассылок без вашего отдельного согласия.

3. Хранение и защита

Данные хранятся на сервере сайта и, при необходимости, передаются в мессенджер Telegram для оперативной обработки заявки. Мы принимаем разумные меры для защиты данных от несанкционированного доступа.

4. Файлы cookie и сервисы аналитики

На сайте работает сервис веб-аналитики Яндекс Метрика (ООО «Яндекс»). Он использует файлы cookie и собирает обезличенные сведения о посещениях: просмотренные страницы, источник перехода, действия на странице (в том числе с помощью Вебвизора и карты кликов), тип устройства и браузера, примерное местоположение по IP-адресу. Эти данные помогают нам понимать, как пользуются сайтом, и улучшать его; они обрабатываются Яндексом по его политике конфиденциальности.

Также используются Google Tag Manager и Google Analytics (Google LLC): они с помощью cookie собирают обезличенную статистику посещений и действий на сайте. Данные обрабатываются по политике конфиденциальности Google.

Вы можете отключить сохранение cookie в настройках браузера, отказаться от сбора данных Метрикой с помощью инструкции Яндекса и Google Analytics — с помощью официального расширения. Сайт продолжит работать.
